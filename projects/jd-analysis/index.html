「粘贴链接」需要浏览器扩展

招聘网站只认你自己的登录态，直接在后台去抓会被挡在风控页上。所以这一步交给浏览器扩展：它在你的浏览器里开一个隐藏标签页，把 JD 正文读回来。不装扩展，「粘贴链接」和「上传二维码」都用不了；「上传截图」和「20 题分析我现在的工作」不需要扩展。

  1. 找到本工具文件夹（启动.bat 所在的那个文件夹），里面的 extension 就是要装的扩展目录。 不知道文件夹在哪：先打开本工具文件夹，点一下窗口的地址栏把完整路径复制下来，再把 extension 接在末尾。
  2. 浏览器地址栏输入 edge://extensions 回车（Chrome 用 chrome://extensions）→ 打开左下角（有的版本在右下角）的「开发人员模式」。
  3. 点「加载解压缩的扩展」→ 选中刚复制的 extension 目录 → 回到本页按 F5 刷新。
